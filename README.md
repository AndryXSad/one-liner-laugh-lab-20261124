One short funny line answering a prompt: the excuse a robot vacuum gives
after eating a sock.

> I didn't eat your sock — I rehomed it. Rent-free, climate-controlled, and inside me.

The joke is a deadpan bureaucratic excuse: "rehomed" is the euphemism a
vacuum would use instead of "ate", and the punchline reframes the dustbin
as luxury housing. The humour comes from the vacuum treating the sock like
a rescue pet it adopted, which fits the situation exactly — a vacuum's
whole job is sucking loose things into itself.

## How it is made

`main.py` is the entrypoint the grader runs. It is deterministic and uses
only the standard library: it writes the single line (84 characters) to
`entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (default
`/output`), with no trailing newline, and reads the file back to check it
is byte-identical.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
```
